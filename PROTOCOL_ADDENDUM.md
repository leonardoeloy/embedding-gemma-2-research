# Secondary analysis addendum — before competitor inference

The original protocol remains unchanged and hash-pinned. After freezing it, the official Ovis repository was found to include the required learned elastic projection matrices and an integration guide at `Adaptor/README.md`. Add an exploratory secondary comparison at 512/256/128 dimensions using those exact matrices: `(embedding @ M_dD)[:, :D]`, followed by L2 normalization for both sides. Record matrix hashes. Do not use prefix slicing for Ovis.

This adds no new model inference, changes no data, native-dimensional primary outcome, model selection, query instruction or filtering baseline, and does not select dimensions based on outcome. It enables a useful same-width storage comparison across all three models. EmbeddingGemma's preliminary native result was already inspected when this addendum was written; secondary results were not inspected. Treat the added Ovis projection analysis as exploratory, not preregistered.

Terminology clarification: the paired metric measures success on both requirement variants for a fixed topic/family/representation/paraphrase. Most variants reverse a requirement, but the version family uses nested compatibility thresholds. Therefore use “paired variant success,” rather than treating every pair as a logical negation pair. The dataset and scoring rule are unchanged.

Exploratory external check: run the complete published NevIR test split (`orionweller/NevIR`, revision `6263585072ce3b435ed09658613553fbf4e74184`) with all three models' unchanged native retrieval formats. Keep each original document pair and both associated queries. Report per-query strict accuracy and pair accuracy requiring both query rankings to be strictly correct; ties count as failures. Include BM25 and independent seeded random rankings. Do not train, select subsets, tune instructions, add synthetic metadata, or apply structured filters to NevIR. This is external validation of negation retrieval, not a new benchmark claim, and was added after seeing the initial catalog results.
